# 📊 Pesquisa de Satisfação

Projeto desenvolvido em **Python** para realizar uma pesquisa de satisfação com **50 entrevistados**.

## 🎯 Objetivo

O programa coleta o **nome**, a **idade** e a **opinião** dos entrevistados sobre o atendimento recebido.

As opções de avaliação são:

* ⭐ **1 - Excelente**
* 👍 **2 - Bom**
* 👎 **3 - Ruim**

Ao final da pesquisa, o programa apresenta a quantidade de respostas para cada avaliação.

## 🛠️ Tecnologias utilizadas

* 🐍 Python
* 🔄 Estrutura de repetição `for`
* 🔀 Estruturas de decisão `if`, `elif` e `else`
* 🔢 Variáveis e contadores
* ⌨️ Entrada de dados com `input()`

## 📌 Funcionamento

O programa realiza a pesquisa com **50 pessoas**, registra cada avaliação e utiliza contadores para calcular a quantidade de respostas:

EXCELENTE → 1
BOM       → 2
RUIM      → 3

No final, os resultados são exibidos no terminal.
